#  【什么是 Utaun？】  
这是一款仅通过完全无生物的加算合成来生成 UTAU 用 CV 音源的 Windows 软件。  
它会在“文档”文件夹中自动生成音源 ZIP。  

#  【特点】   
 ・运行后自动在文档中生成音源 ZIP  
 ・通过完全无生物的加算合成生成元音（あ・い・う・え・お・ん）  
 ・通过与外部辅音行（か行～ぱ行）组合来生成 CV 音源  
 ・内部生成 m / n / y / w 行  
 ・支持平假名别名 + 英语罗马字别名（发音全部为日语）  
 ・自动生成 oto.ini / character.txt / readme.txt  
 ・可以将 PNG 图像转换为 JPG  
 ・为防止乱码，readme.txt 和 character.txt 以 Shift_JIS (ANSI) 编码输出  
 ・可以更改基频（声音高度）  
 ・可以自由设置音源名称（角色名称）  

#  【预期用途】  
 ・想用无生物的声音制作 UTAU 音源时  
 ・适合不擅长用原声录音的人制作音源  
 ・加算合成语音的素材研究  
 ・自制音源的原型制作  
 ・解压 ZIP 后直接作为人力 VOCALOID 素材使用  
 ・作为音MAD・YTPMV 等的素材用途  

#  【Utaun 的使用方法】  
 ① 下载 `Utaun.ver-1.0.3.zip`。（请从 Releases 下载。）  
 ② 展开（解压）`Utaun.ver-1.0.3.zip`。  
 ③ 将 `Utaun.exe` 放在任意文件夹中（推荐桌面）。  
 ④ 启动 `Utaun.exe` 并按照屏幕上的指示操作。  
 ⑤ 当显示“（音源名）.zip がドキュメントに出来上がったよ！”时，UTAU 音源即告完成。

#  【生成的主 UTAU 音源的使用方法】  
 ・UTAU  
   解压生成的 ZIP，即可展开可直接导入 UTAU 的音源文件夹。  
 ・OpenUTAU  
   可以直接以 ZIP 格式导入（无需解压）。  
 ※ 各软件的具体使用方法，请参考各自的帮助、手册或官方文档。  

#  【运行环境】  
 ・Windows 10～11 (64bit)  
 ・Windows 10～11 (32bit)  

**【未支持功能】**  
 ・浊音元音（あ゙・い゙・ゔ・え゙・お゙）  
 ・耳语、呼吸音、气声等表情差分  
 ・拗音（きゃ・きゅ・きょ / しゃ・しゅ・しょ 等）  
 ・连续音（VCV）  
 ・CVVC  
 ・其他特殊发音  

#  【使用条款】  
在 Utaun 本体（`Utaun.exe`）中，禁止以下行为：  
 ・加工  
 ・编辑  
 ・改造  
 ・商业利用  
 ・再分发  
 ・反编译（分解）
