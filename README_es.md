#  【¿Qué es Utaun?】  
Es un software para Windows que genera bancos de voz CV para UTAU utilizando puramente síntesis aditiva inanimada.  
Genera automáticamente un ZIP del banco de voz en tu carpeta Documentos.  

#  【Características】   
 ・Genera automáticamente un ZIP del banco de voz en Documentos al ejecutarse  
 ・Generación de vocales (a, i, u, e, o, n) mediante síntesis aditiva puramente inanimada  
 ・Genera bancos de voz CV combinando con filas de consonantes externas (filas de ka a pa)  
 ・Generación interna de las filas m / n / y / w  
 ・Compatible con alias en Hiragana + alias en Romaji inglés (todas las pronunciaciones son en japonés)  
 ・Genera automáticamente oto.ini / character.txt / readme.txt  
 ・Puede convertir imágenes PNG a JPG  
 ・Los archivos readme.txt y character.txt se exportan en Shift_JIS (ANSI) para evitar problemas de codificación  
 ・Puedes cambiar la frecuencia fundamental (tono de la voz)  
 ・Puedes configurar libremente el nombre del banco de voz (nombre del personaje)  

#  【Usos previstos】  
 ・Cuando quieres crear un banco de voz UTAU con una voz inanimada  
 ・Creación de bancos de voz para personas a las que les cuesta grabar con su propia voz  
 ・Investigación de materiales de voz por síntesis aditiva  
 ・Prototipado de bancos de voz propios  
 ・Descomprimir el ZIP y usarlo directamente como material de Vocaloid hecho por humanos (Jinkiri-VOCALOID)  
 ・Uso como material para OtoMADs, YTPMVs, etc.  

#  【Cómo usar Utaun】  
 ① Descarga `Utaun.ver-1.0.3.zip`. (Por favor, descárgalo desde Releases.)  
 ② Extrae (descomprime) `Utaun.ver-1.0.3.zip`.  
 ③ Coloca `Utaun.exe` en cualquier carpeta (se recomienda el Escritorio).  
 ④ Inicia `Utaun.exe` y sigue las instrucciones en pantalla.  
 ⑤ Cuando aparezca "（音源名）.zip がドキュメントに出来上がったよ！", el banco de voz de UTAU estará completo.

#  【Cómo usar el banco de voz UTAU generado】  
 ・UTAU  
   Al descomprimir el ZIP generado, se despliega una carpeta de banco de voz que se puede cargar directamente en UTAU.  
 ・OpenUTAU  
   Se puede cargar directamente en formato ZIP (sin necesidad de descomprimir).  
 ※ Consulta la ayuda, los manuales y la documentación oficial de cada software para ver las instrucciones específicas de uso.  

#  【Requisitos del sistema】  
 ・Windows 10–11 (64-bit)  
 ・Windows 10–11 (32-bit)  

**【No compatible / No soportado】**  
 ・Vocales con dakuten (あ゙・い゙・ゔ・え゙・お゙)  
 ・Variaciones expresivas como susurros, respiraciones y componentes de aire  
 ・Sonidos contraídos (kya, kyu, kyo / sha, shu, sho, etc.)  
 ・VCV (Sonido Continuo)  
 ・CVVC  
 ・Otras pronunciaciones especiales
