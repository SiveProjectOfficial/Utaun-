​#  【Utaun이란?】  
완전 무생물의 가산 합성만으로 UTAU용 CV 음원을 생성하는 Windows 소프트웨어입니다.  
문서 폴더에 음원 ZIP을 자동으로 생성합니다.  

#  【특징】   
 ・실행하면 문서에 음원 ZIP을 자동 생성  
 ・완전 무생물의 가산 합성을 통한 모음 생성 (아・이・우・에・오・응)  
 ・외부 자음 행(か행~ぱ행)과의 조합으로 CV 음원 생성  
 ・m / n / y / w 행 내부 생성  
 ・히라가나 별칭 + 영어 로마자 별칭 지원 (발음은 모두 일본어)  
 ・oto.ini / character.txt / readme.txt 자동 생성  
 ・PNG 이미지를 JPG로 변환 가능  
 ・readme.txt와 character.txt는 글자 깨짐 방지를 위해 Shift_JIS(ANSI)로 출력  
 ・기본 주파수(목소리 높낮이) 변경 가능  
 ・음원 이름(캐릭터 이름)을 자유롭게 설정 가능  

#  【상정 용도】  
 ・무생물의 목소리로 UTAU 음원을 만들고 싶을 때  
 ・생목소리로 녹음하는 것이 부담스러운 사람을 위한 음원 제작  
 ・가산 합성 음성 소재 연구  
 ・자작 음원 프로토타이핑  
 ・ZIP을 압축 해제하여 그대로 인력보카로(Jinkiri-VOCALOID) 소재로 사용하는 용도  
 ・음MAD・YTPMV 등의 소재로 사용하는 용도  

#  【Utaun 사용 방법】  
 ① `Utaun.ver-1.0.3.zip`을 다운로드합니다. (Releases에서 다운로드해 주세요.)  
 ② `Utaun.ver-1.0.3.zip`을 전개(압축 해제)합니다.  
 ③ `Utaun.exe`를 임의의 폴더(바탕화면 권장)에 놓습니다.  
 ④ `Utaun.exe`를 실행하고 화면의 지시를 따릅니다.  
 ⑤ "（音源名）.zip がドキュメントに出来上がったよ！"((음원 이름).zip이 문서에 완성되었어!)라고 표시되면 UTAU 음원 완성입니다.

#  【생성한 UTAU 음원 사용 방법】  
 ・UTAU  
   생성된 ZIP을 압축 해제하면 그대로 UTAU에 불러올 수 있는 음원 폴더가 전개됩니다.  
 ・OpenUTAU
