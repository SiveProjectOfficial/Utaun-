#  【乜嘢係 Utaun？】  
呢個係一套只透過完全無生物嘅加算合成嚟生成 UTAU 用 CV 音源嘅 Windows 軟件。  
佢會在「文件」文件夾入面自動生成音源 ZIP。  

#  【特點】   
 ・執行之後會喺文件入面自動生成音源 ZIP  
 ・透過完全無生物嘅加算合成生成元音（あ・い・う・え・お・ん）  
 ・透過同外部子音行（か行～ぱ行）組合嚟生成 CV 音源  
 ・內部生成 m / n / y / w 行  
 ・支援平假名別名 + 英語羅馬字別名（發音全部都係日文）  
 ・自動生成 oto.ini / character.txt / readme.txt  
 ・可以將 PNG 影像轉成 JPG  
 ・為了防止亂碼，readme.txt 同 character.txt 係用 Shift_JIS (ANSI) 輸出  
 ・可以更改基本頻率（聲高）  
 ・可以自由設定音源名（角色名）  

#  【預期用途】  
 ・想用無生物嘅聲去整 UTAU 音源嗰陣  
 ・畀啲唔慣用自己把聲錄音嘅人去整音源  
 ・加算合成語音嘅素材研究  
 ・自製音源嘅原型製作  
 ・解壓 ZIP 之後直接當係人力 VOCALOID 素材用  
 ・用做音MAD・YTPMV 等嘅素材  

#  【Utaun 嘅使用方法】  
 ① 下載 `Utaun.ver-1.0.3.zip`。（請由 Releases 度下載。）  
 ② 展開（解壓）`Utaun.ver-1.0.3.zip`。  
 ③ 將 `Utaun.exe` 擺喺任何一個文件夾度（建議桌面）。  
 ④ 啟動 `Utaun.exe`，然後跟住畫面嘅指示去做。  
 ⑤ 當顯示「（音源名）.zip がドキュメントに出来上がったよ！」嘅時候，UTAU 音源就完成喇。
