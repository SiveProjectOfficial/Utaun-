#  【Was ist Utaun?】  
Eine Windows-Software, die CV-Voicebanks für UTAU ausschließlich durch rein leblose additive Synthese generiert.  
Sie erstellt automatisch eine Voicebank-ZIP-Datei im Ordner „Dokumente“.  

#  【Eigenschaften】   
 ・Generiert beim Ausführen automatisch eine Voicebank-ZIP-Datei in den Dokumenten  
 ・Vokalgenerierung (a, i, u, e, o, n) durch rein leblose additive Synthese  
 ・Erstellt CV-Voicebanks durch Kombination mit externen Konsonantenreihen (Ka- bis Pa-Reihe)  
 ・Interne Generierung der Reihen m / n / y / w  
 ・Unterstützt Hiragana-Aliase + englische Romaji-Aliase (alle Aussprachen sind auf Japanisch)  
 ・Generiert automatisch oto.ini / character.txt / readme.txt  
 ・Kann PNG-Bilder in JPG konvertieren  
 ・readme.txt und character.txt werden in Shift_JIS (ANSI) ausgegeben, um Zeichensalat zu verhindern  
 ・Die Grundfrequenz (Tonhöhe) kann geändert werden  
 ・Der Name der Voicebank (Charaktername) kann frei festgelegt werden  

#  【Vorgesehene Verwendung】  
 ・Wenn Sie eine UTAU-Voicebank mit einer leblosen Stimme erstellen möchten  
 ・Erstellung von Voicebanks für Personen, denen das Aufnehmen mit der eigenen Stimme schwerfällt  
 ・Materialforschung für additiv synthetisierte Stimmen  
 ・Prototyping eigener Voicebanks  
 ・Entpacken der ZIP-Datei und direkte Verwendung als von Menschen gemachtes Vocaloid-Material (Jinkiri-VOCALOID)  
 ・Verwendung als Material für OtoMADs, YTPMVs usw.  

#  【Verwendung von Utaun】  
 ① Laden Sie `Utaun.ver-1.0.3.zip` herunter. (Bitte von Releases herunterladen.)  
 ② Entpacken Sie `Utaun.ver-1.0.3.zip`.  
 ③ Legen Sie `Utaun.exe` in einen beliebigen Ordner (Desktop empfohlen).  
 ④ Starten Sie `Utaun.exe` und folgen Sie den Anweisungen auf dem Bildschirm.  
 ⑤ Wenn „（音源名）.zip がドキュメントに出来上がったよ！“ angezeigt wird, ist die UTAU-Voicebank fertig.

#  【Verwendung der generierten UTAU-Voicebank】  
 ・UTAU  
   Durch das Entpacken des generierten ZIPs erhalten Sie einen Voicebank-Ordner, der direkt in UTAU geladen werden kann.  
 ・OpenUTAU  
   Kann direkt als ZIP-Datei geladen werden (kein Entpacken erforderlich).  
 ※ Bitte beachten Sie die jeweiligen Hilfen, Handbücher und offiziellen Dokumentationen der Software für spezifische Nutzungshinweise.  

#  【Systemanforderungen】  
 ・Windows 10–11 (64-bit)  
 ・Windows 10–11 (32-bit)  

**【Nicht unterstützt】**  
 ・Stimmhafte Vokale mit Dakuten (あ゙・い゙・ゔ・え゙・お゙)  
 ・Ausdrucksstarke Variationen wie Flüstern, Atemgeräusche, Hauchkomponenten usw.  
 ・Kontrahierte Laute (kya, kyu, kyo / sha, shu, sho usw.)  
 ・VCV (Kontinuierlicher Klang)  
 ・CVVC  
 ・Sonstige Spezialaussprachen
