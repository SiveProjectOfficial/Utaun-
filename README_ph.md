#  【Ano ang Utaun?】  
Isa itong Windows software na lumilikha ng mga UTAU CV voicebank gamit ang purong inanimate additive synthesis.  
Awtomatiko itong gumagawa ng voicebank ZIP sa iyong Documents folder.  

#  【Mga Katangian / Tampok】   
 ・Awtomatikong gumagawa ng voicebank ZIP sa Documents kapag pinatakbo  
 ・Pagbuo ng mga patinig (a, i, u, e, o, n) sa pamamagitan ng purong inanimate additive synthesis  
 ・Bumubuo ng mga CV voicebank sa pamamagitan ng pagsasama sa mga panlabas na hilera ng katinig (mula sa hilera ng ka hanggang pa)  
 ・Panloob na pagbuo ng mga hilera ng m / n / y / w  
 ・Suporta sa Hiragana aliases + English Romaji aliases (lahat ng bigkas ay sa wikang Hapon)  
 ・Awtomatikong gumagawa ng oto.ini / character.txt / readme.txt  
 ・Kaya nitong i-convert ang mga PNG image patungong JPG  
 ・Ang readme.txt at character.txt ay naka-output sa Shift_JIS (ANSI) upang maiwasan ang character corruption  
 ・Maaari mong baguhin ang pangunahing dalas o pitch ng boses (fundamental frequency)  
 ・Malaya mong mapipili at maiaayos ang pangalan ng voicebank (pangalan ng karakter)  

#  【Mga Inaasahang Gamit】  
 ・Kapag gusto mong gumawa ng UTAU voicebank na may boses na non-living o inanimate  
 ・Paggawa ng voicebank para sa mga taong nahihirapang mag-record gamit ang sarili nilang boses  
 ・Pananaliksik sa materyal ng additive synthesis voice  
 ・Prototyping ng sariling gawang voicebank  
 ・Pag-extract ng ZIP at direktang paggamit nito bilang materyal para sa human-made Vocaloid (Jinkiri-VOCALOID)  
 ・Paggamit bilang materyal para sa OtoMADs, YTPMVs, atbp.  

#  【Paano Gamitin ang Utaun】  
 ① I-download ang `Utaun.ver-1.0.3.zip`. (Mangyaring i-download ito mula sa Releases.)  
 ② I-extract (i-unzip) ang `Utaun.ver-1.0.3.zip`.  
 ③ Ilagay ang `Utaun.exe` sa anumang folder (inirerekomenda sa Desktop).  
 ④ Buksan ang `Utaun.exe` at sundin ang mga tagubilin sa screen.  
 ⑤ Kapag lumabas ang mensaheng "（音源名）.zip がドキュメントに出来上がったよ！", tapos na ang UTAU voicebank.
