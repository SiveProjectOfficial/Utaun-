#  【什麼是 Utaun？】  
這是一款僅透過完全無生物的加算合成來生成 UTAU 用 CV 音源的 Windows 軟體。  
會在「文件」資料夾中自動生成音源 ZIP。  

#  【特點】   
 ・執行後會在文件中自動生成音源 ZIP  
 ・透過完全無生物的加算合成生成母音（あ・い・う・え・お・ん）  
 ・透過與外部子音行（か行～ぱ行）組合來生成 CV 音源  
 ・內部生成 m / n / y / w 行  
 ・支援平假名別名 + 英語羅馬字別名（發音全部為日語）  
 ・自動生成 oto.ini / character.txt / readme.txt  
 ・可以將 PNG 影像轉換為 JPG  
 ・為了防止亂碼，readme.txt 與 character.txt 是以 Shift_JIS (ANSI) 輸出  
 ・可以變更基本頻率（聲音高低）  
 ・可以自由設定音源名稱（角色名稱）  

#  【預期用途】  
 ・想用無生物的聲音製作 UTAU 音源時  
 ・適合不擅長用原聲錄音的人製作音源  
 ・加算合成語音的素材研究  
 ・自製音源的原型製作  
 ・解壓 ZIP 後直接作為人力 VOCALOID 素材使用  
 ・作為音MAD・YTPMV 等的素材用途  

#  【Utaun 的使用方法】  
 ① 下載 `Utaun.ver-1.0.3.zip`。（請從 Releases 下載。）  
 ② 展開（解壓縮）`Utaun.ver-1.0.3.zip`。  
 ③ 將 `Utaun.exe` 放在任意資料夾中（建議放在桌面）。  
 ④ 啟動 `Utaun.exe` 並依照畫面指示操作。  
 ⑤ 當顯示「（音源名）.zip がドキュメントに出來上がったよ！」時，UTAU 音源即完成。

#  【生成的 UTAU 音源使用方法】  
 ・UTAU  
   解壓縮生成的 ZIP 後，會展開可直接讀取至 UTAU 的音源資料夾。  
 ・OpenUTAU  
   可以直接以 ZIP 讀取（無需解壓縮）。  
 ※ 各軟體的具體使用方法，請參照各自的說明檔、手冊或官方文件。  

#  【執行環境】  
 ・Windows 10～11 (64bit)  
 ・Windows 10～11 (32bit)  

**【未支援項目】**  
 ・濁音母音（あ゙・い゙・ゔ・え゙・お゙）  
 ・氣音、呼吸聲、氣息成分等表情差分  
 ・拗音（きゃ・きゅ・きょ / しゃ・しゅ・しょ 等）  
 ・連續音（VCV）  
 ・CVVC  
 ・其他特殊發音  

#  【使用條款】  
針對 Utaun 本體（`Utaun.exe`），禁止以下行為：  
 ・加工  
 ・編輯  
 ・改造  
 ・商業利用  
 ・再散布  
 ・反編譯（分解）
