#  【Что такое Utaun?】  
Это программа для Windows, которая генерирует CV-войсбанки для UTAU исключительно с помощью неживого аддитивного синтеза.  
Она автоматически создаёт ZIP-архив войсбанка в папке «Документы».  

#  【Особенности】   
 ・Автоматически создаёт ZIP-архив войсбанка в папке «Документы» при запуске  
 ・Генерация гласных (あ・い・う・え・お・ん) с помощью чисто неживого аддитивного синтеза  
 ・Создание CV-войсбанков путем комбинации с внешними рядами согласных (от ряда ka до pa)  
 ・Внутренняя генерация рядов m / n / y / w  
 ・Поддержка псевдонимов на хирагане + английских ромадзи-псевдонимов (все произношения на японском)  
 ・Автоматическое создание oto.ini / character.txt / readme.txt  
 ・Возможность конвертировать изображения PNG в JPG  
 ・Файлы readme.txt и character.txt выводятся в кодировке Shift_JIS (ANSI) для предотвращения кракозябр  
 ・Возможность менять основную частоту (высоту голоса)  
 ・Свободная настройка имени войсбанка (имени персонажа)  

#  【Предполагаемое использование】  
 ・Когда вы хотите создать войсбанк UTAU с неживым голосом  
 ・Создание войсбанков для тех, кто не любит записывать собственный голос  
 ・Исследование материалов аддитивного синтеза речи  
 ・Прототипирование собственных войсбанков  
 ・Распаковка ZIP и использование напрямую в качестве материала для ручного вокалоида (Jinkiri-VOCALOID)  
 ・Использование в качестве материала для OtoMAD, YTPMV и т.д.  

#  【Как использовать Utaun】  
 ① Скачайте `Utaun.ver-1.0.3.zip`. (Скачивайте из раздела Releases.)  
 ② Распакуйте `Utaun.ver-1.0.3.zip`.  
 ③ Поместите `Utaun.exe` в любую папку (рекомендуется рабочий стол).  
 ④ Запустите `Utaun.exe` и следуйте инструкциям на экране.  
 ⑤ Когда появится сообщение «（音源名）.zip がドキュメントに出来上がったよ!», войсбанк UTAU готов.

#  【Как использовать сгенерированный войсбанк UTAU】  
 ・UTAU  
   Распакуйте полученный ZIP, чтобы получить папку войсбанка, которую можно напрямую загрузить в UTAU.  
 ・OpenUTAU  
   Можно загружать прямо в виде ZIP (без распаковки).  
 ※ Подробные инструкции по использованию в каждой программе см. в соответствующих справках, руководствах и официальной документации.  

#  【Системные требования】  
 ・Windows 10–11 (64-bit)  
 ・Windows 10–11 (32-bit)  

**【Не поддерживается】**  
 ・Озвученные гласные (あ゙・い゙・ゔ・え゙・お゙)  
 ・Выразительные вариации (шепот, дыхание, компоненты вздоха и т.д.)  
 ・Смягченные/сокращенные звуки (кя, кю, кё / ся, сю, сё и т.д.)  
 ・VCV (Континуальные звуки)  
 ・CVVC  
 ・Другие специальные произношения
