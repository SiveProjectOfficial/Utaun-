#  【Cos'è Utaun?】  
È un software per Windows che genera banchi voce CV per UTAU utilizzando puramente la sintesi additiva inanimata.  
Genera automaticamente un file ZIP del banco voce nella cartella Documenti.  

#  【Caratteristiche】   
 ・Genera automaticamente un file ZIP del banco voce in Documenti all'avvio  
 ・Generazione delle vocali (a, i, u, e, o, n) tramite sintesi additiva puramente inanimata  
 ・Genera banchi voce CV combinandoli con le righe di consonanti esterne (dalla riga ka alla riga pa)  
 ・Generazione interna delle righe m / n / y / w  
 ・Supporta alias in Hiragana + alias in Romaji inglese (tutte le pronunce sono in giapponese)  
 ・Genera automaticamente oto.ini / character.txt / readme.txt  
 ・Può convertire immagini PNG in JPG  
 ・I file readme.txt e character.txt vengono esportati in Shift_JIS (ANSI) per evitare problemi di codifica dei caratteri  
 ・Puoi modificare la frequenza fondamentale (l'altezza della voce)  
 ・Puoi impostare liberamente il nome del banco voce (nome del personaggio)  

#  【Usi previsti】  
 ・Quando vuoi creare un banco voce UTAU con una voce inanimata  
 ・Creazione di banchi voce per persone che hanno difficoltà a registrare con la propria voce  
 ・Ricerca di materiali per voci a sintesi additiva  
 ・Prototipazione di banchi voce personali  
 ・Decomprimere lo ZIP e usarlo direttamente come materiale per Vocaloid fatto da umani (Jinkiri-VOCALOID)  
 ・Utilizzo come materiale per OtoMAD, YTPMV, ecc.  

#  【Come usare Utaun】  
 ① Scarica `Utaun.ver-1.0.3.zip`. (Si prega di scaricarlo da Releases.)  
 ② Estrai (decomprimi) `Utaun.ver-1.0.3.zip`.  
 ③ Posiziona `Utaun.exe` in una cartella a scelta (consigliato il Desktop).  
 ④ Avvia `Utaun.exe` e segui le istruzioni sullo schermo.  
 ⑤ Quando viene visualizzato "（音源名）.zip がドキュメントに出来上がったよ！", il banco voce UTAU è completato.

#  【Come usare il banco voce UTAU generato】  
 ・UTAU  
   Decomprimendo lo ZIP generato si ottiene una cartella del banco voce che può essere caricata direttamente in UTAU.  
 ・OpenUTAU  
   Può essere caricato direttamente come file ZIP (senza necessità di estrazione).  
 ※ Si prega di fare riferimento alla guida, ai manuali e alla documentazione ufficiale di ciascun software per le modalità d'uso specifiche.  

#  【Requisiti di sistema】  
 ・Windows 10–11 (64-bit)  
 ・Windows 10–11 (32-bit)  

**【Non supportato】**  
 ・Vocali con dakuten (あ゙・い゙・ゔ・え゙・お゙)  
 ・Variazioni espressive come sussurri, respiri e componenti d'aria  
 ・Suoni contratti (kya, kyu, kyo / sha, shu, sho, ecc.)  
 ・VCV (Suono Continuo)  
 ・CVVC  
 ・Altre pronunce speciali
