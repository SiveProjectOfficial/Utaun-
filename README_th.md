#  【Utaun คืออะไร?】  
เป็นซอฟต์แวร์ Windows ที่สร้างเสียงร้องแบบ CV สำหรับ UTAU โดยใช้การสังเคราะห์แบบแอดдиทีฟจากวัตถุปิดตาย/ไม่มีชีวิตอย่างสมบูรณ์  
ซอฟต์แวร์นี้จะสร้าง ZIP ของเสียงร้องในโฟลเดอร์ Documents ของคุณโดยอัตโนมัติ  

#  【คุณสมบัติ】   
 ・สร้างไฟล์ ZIP ของเสียงร้องใน Documents โดยอัตโนมัติเมื่อรันโปรแกรม  
 ・สร้างสระ (あ・い・う・え・お・ん) ผ่านการสังเคราะห์แบบแอดдиทีฟจากวัตถุไม่มีชีวิตล้วนๆ  
 ・สร้างเสียงร้องแบบ CV โดยการผสมผสานกับแถวพยัญชนะภายนอก (แถว ka ถึง pa)  
 ・สร้างแถว m / n / y / w ภายในตัว  
 ・รองรับนามแฝงฮิระงะนะ + นามแฝงโรมาจิภาษาอังกฤษ (การออกเสียงทั้งหมดเป็นภาษาญี่ปุ่น)  
 ・สร้างไฟล์ oto.ini / character.txt / readme.txt โดยอัตโนมัติ  
 ・สามารถแปลงภาพ PNG เป็น JPG ได้  
 ・ไฟล์ readme.txt และ character.txt ถูกส่งออกเป็นเข้ารหัส Shift_JIS (ANSI) เพื่อป้องกันตัวอักษรเพี้ยน  
 ・สามารถเปลี่ยนความถี่พื้นฐาน (ระดับเสียงสูงต่ำ) ได้  
 ・สามารถตั้งชื่อเสียงร้อง (ชื่อตัวละคร) ได้อย่างอิสระ  

#  【การใช้งานที่คาด, จุดประสงค์】  
 ・เมื่อคุณต้องการสร้างเสียงร้อง UTAU ด้วยเสียงแบบไม่มีชีวิต  
 ・สำหรับการสร้างเสียงร้องสำหรับผู้ที่ไม่ถนัดในการบันทึกเสียงด้วยเสียงจริงของตนเอง  
 ・การวิจัยวัสดุเสียงสังเคราะห์แบบแอดдиทีฟ  
 ・การทำต้นแบบเสียงร้องที่สร้างขึ้นเอง  
 ・แตกไฟล์ ZIP และนำไปใช้โดยตรงเป็นวัสดุสำหรับ Vocaloid ที่มนุษย์สร้างขึ้นเอง (Jinkiri-VOCALOID)  
 ・ใช้เป็นวัสดุสำหรับ OtoMAD, YTPMV และอื่นๆ  

#  【วิธีใช้งาน Utaun】  
 ① ดาวน์โหลด `Utaun.ver-1.0.3.zip` (โปรดดาวน์โหลดจาก Releases)  
 ② ขยาย (แตกไฟล์) `Utaun.ver-1.0.3.zip`  
 ③ วาง `Utaun.exe` ไว้ในโฟลเดอร์ใดก็ได้ (แนะนำหน้าเดสก์ท็อป)  
 ④ เปิดใช้งาน `Utaun.exe` และทำตามคำแนะนำบนหน้าจอ  
 ⑤ เมื่อข้อความ "（音源名）.zip がドキュメントに出来上がったよ！" ปรากฏขึ้น แสดงว่าเสียงร้อง UTAU เสร็จสมบูรณ์แล้ว

#  【วิธีใช้งานเสียงร้อง UTAU ที่สร้างขึ้น】  
 ・UTAU  
   เมื่อแตกไฟล์ ZIP ที่สร้างขึ้น จะได้โฟลเดอร์เสียงร้องที่สามารถโหลดเข้า UTAU ได้ทันที  
 ・OpenUTAU  
   สามารถโหลดเข้าโปรแกรมในรูปแบบไฟล์ ZIP ได้เลย (ไม่ต้องแตกไฟล์)  
 ※ โปรดอ้างอิงวิธีใช้งานเฉพาะของแต่ละซอฟต์แวร์จากคู่มือ ความช่วยเหลือ หรือเอกสารอย่างเป็นทางการของซอฟต์แวร์นั้นๆ
